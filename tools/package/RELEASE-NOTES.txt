CTR Reload @VERSION@ (@BUILD@) - Release notes
==============================================

This version is for track authors who test their own tracks with
Reload Studio.


DECISIONS
---------
- Windows only. There is no Linux version, and none is planned. Linux build
  files in the source code are not maintained.
- Bug reports go to GitHub issues with the "Bug report" form, see section 8
  of README.txt:
  https://github.com/LinksTech/CTR-Reload-Edition/issues/new/choose
- The package ships the game and Reload Studio. The track packer rldpack is
  built into Reload Studio and is not a separate program in the package.


NEW IN THIS VERSION
-------------------
- The Alpha-Maker is now called Reload Studio (ReloadStudio.exe; Beta 0
  shipped it as alphamaker.exe). Its settings move once from alphamaker.ini
  to reloadstudio.ini (the old file stays); its test and preview logs are
  now in %TEMP%\Reload Studio.
- A track with a broken minimap table no longer crashes the race; it shows no
  minimap. Reload Studio warns about it.
- Object limit: Reload Studio refuses tracks with more than 110 placed
  objects and warns above 90. If the game ever runs out of room, it says so
  in the log and leaves out an effect (an explosion, a flame) instead of
  crashing.
- Folder and file names with any characters work (for example a Windows user
  name with accents or Cyrillic letters).
- Logs are kept: every start writes a new log with date and time in the
  "logs" folder, the last 5 stay. Reload Studio keeps its last 5 test and
  preview logs the same way.
- OPTIONS -> GRAPHICS: display mode, aspect ratio, resolution, anti-aliasing.
  Saved and restored at the next start.
- Track previews in the track selection screen. "Build container" in
  Reload Studio records the preview by itself, in the background (about 20
  seconds, no game window). The preview shows a drive along your track from
  the driver's view (needs bot data / nav paths; without them a camera flies
  along the restart points). If the preview cannot be recorded, the
  container is still built, and Reload Studio says why ("preview skipped"
  or "preview failed"). A preview game that has not finished after 2 minutes
  is stopped.
- Reload Studio checks that the game next to it is from the same package.
  If the game it remembered from an earlier session is from another package,
  it switches once to ctr_native.exe in its own folder and says so.
- Crystal Challenge for custom tracks: ARCADE -> NITRO-PIT -> CRYSTAL. Collect
  every crystal before the time runs out. Win or lose, you get RETRY or back
  to NITRO-PIT; nothing is written to your adventure save. Reload Studio
  ticks every mode your track has the data for.
- CTR Challenge for custom tracks: ARCADE -> NITRO-PIT -> CTR. Win with 1st
  place and all three letters C, T and R. Win or lose, you get RETRY or back
  to NITRO-PIT; nothing is written to your adventure save. The track needs
  each of the letters C, T and R exactly once; bots need nav paths.
- A track that offers several modes is listed under each of them (RACE,
  CRYSTAL, CTR). Cups are race only.
- Custom tracks start without the camera fly-in before the countdown, even
  if the track has its own camera path. Disc tracks keep their fly-in.
- "Build container" sets the ids of the letter models c, t and r by their
  names, so the HUD shows C T R in that order. When it changes one, it says
  so in its messages.
- Custom characters: put .rldchar files into the new "characters" folder next
  to the game. Each gets a tile in the one-player ARCADE driver select, after
  the original drivers (at most 32). A broken file is skipped, the game starts
  anyway and the log says why.
- Reload Studio has a new page "Character": a PLY model of driver, steering
  wheel and kart, a name, a driving style, a size, an optional icon and an
  optional voices folder. It checks while you type, shows the model as the
  game will draw it (turnable, three poses, next to an original kart) and
  builds the .rldchar. The page always builds on Fake Crash; it asks for no
  original driver to start from.
- The driving style (Balanced, Acceleration, Speed, Turning) decides how a
  custom character's kart drives and its engine sound.
- The size makes only the driver and the steering wheel larger or smaller;
  the kart keeps its size. Visual size only - physics and collision follow
  the driving style.
- Crash is the standard size: every character model is fitted to the size
  of Crash with his kart, whatever scale it was exported in. Its kart gets
  the length of Crash's kart (112.4 game units); with "Show kart wheels" off
  the whole model gets that length. It never gets taller than the tallest
  original driver. The size slider works from there: 100 % = Crash size.
  The preview shows a dashed "Crash size" box. For scripts: rldpack
  make-char --fit crash is the default; --fit none keeps the exported size
  and is the only mode that takes --scale, so a script that passes --scale
  now needs --fit none as well.
- Automatic reduction: a model with more triangles than the game has draw
  memory for (805 triangles without textures - as much as N. Oxide, the most
  any original driver uses) is reduced to at most 797 triangles, only as far
  as needed. The shape and the colours stay, kart, driver and steering wheel
  are reduced each on its own, and the same model always gives the same
  result. Reload Studio shows the triangles and the draw memory before and
  after and says "reduced automatically". The check box "Reduce
  automatically" (on by default; rldpack make-char --reduce off) brings back
  the old refusal.
- Faces with more than four corners are split into triangles; only faces
  that cannot be split (twisted, or without area) are still refused.
- Kart wheels on or off: the check box "Show kart wheels" (on by default;
  rldpack make-char --wheels off) is stored in the .rldchar. Off is for
  models that bring their own wheels or their own vehicle: the game then
  draws no kart wheels (and no wheel reflections) for that driver; tyre dust
  and skid marks stay. An older game ignores the setting and draws the
  wheels. Details of the file: docs/CONTAINER_FORMAT.md in the source code.


KNOWN ISSUES
------------
- Custom tracks: Race, Crystal Challenge and CTR Challenge. Time Trial and
  Battle are planned. Best times on custom tracks are not saved.
- A track that offers both Race and Crystal Challenge is not tested yet: no
  test track has both restart points and crystals.
- A track with only Crystal Challenge cannot get a preview; the preview is
  recorded in a race.
- CTR Challenge: letters that the exporter wrote without a collision hitbox
  cannot be collected, so the challenge cannot be won. Reload Studio does
  not check this yet.
- Crystal Challenge: the time limit is fixed at 3:00 for every track for now.
- No bots and no auto drive on tracks without nav paths. In a CTR Challenge
  1st place is then easy.
- Multiplayer (VS., BATTLE, 2 players) is locked.
- Custom characters are silent: Reload Studio checks voice files, but does
  not pack them yet.
- A custom character's icon is packed when you give one, but the game does
  not show it yet: the driver select shows the portrait of Fake Crash.
- Custom characters only in the one-player ARCADE driver select; not in
  NITRO-PIT CRYSTAL or CTR, Time Trial, Adventure, Battle or with two
  players.
- Custom characters with "Show kart wheels" off: tyre dust and skid marks
  still show where the game's wheels would be.
- Very large tracks: flickering holes near the camera are possible when a
  track has very coarse BSP leaves. The log then contains
  "rendered list full" - please report it, with the track's file name and
  SHA-256.
- Track previews: the invisible kart still hits crates and fruit, so they
  break in the preview. If it falls off, the mask carries it back.
- Track previews without nav paths: the camera does not avoid walls and
  ceilings; it may pass through a tunnel roof.
- Tracks exported with Saphi: a hit may be missed where hitboxes are
  duplicated, and some floors may be black. Always build with "Build
  container" (make); it fixes wrong model ids.
- Music banks above 512 KB load, but their playback is not fully tested yet.
  The ambient sound set in the track options is not tested either.
- Reload Studio starts the game in developer mode for "Test in game" and
  for the preview recording. The "extra arguments" field accepts developer
  switches; you do not need it.
- The executables are not signed. Some virus scanners may warn about them.
- Retail cheat codes that unlock drivers are not saved to the memory card any
  more; all drivers are available from the start anyway.
